---
title: "Quickstart"
description: "Take a test payment in Sandbox in about ten minutes"
---

This guide gets you from a new account to a paid test charge, using testnet coins and no real money.

<Steps>
  <Step title="Create a Sandbox account and API key">
    Sign up at [sandbox.luminpay.co](https://sandbox.luminpay.co), open **Developers → API keys**, and create a key. Sandbox keys start with `lmp_test_`.

    The full key is shown once. Store it in your server's secrets, never in a browser or mobile app.
  </Step>
  <Step title="Create a charge">
    Ask for an amount in naira and the coin the customer will pay with. LuminPay works out the coin amount and returns the payment address.

```bash
curl -X POST https://sandbox-api.luminpay.co/charges \
  -H "Authorization: Bearer $LUMINPAY_TEST_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "amountNgn": "5000",
    "asset": "USDC_ETH_TEST5_AN74",
    "reference": "order_1001"
  }'
```

    The response:

```json
{
  "chargeId": "6f1c2d3e-8a9b-4c5d-9e0f-1a2b3c4d5e6f",
  "reference": "order_1001",
  "amount": "3646209",
  "amountNgn": "500000",
  "feeAmount": "36101",
  "rate": "1385",
  "asset": "USDC_ETH_TEST5_AN74",
  "address": null,
  "addresses": [],
  "txHash": null,
  "expiresAt": "2026-11-06T10:15:00.000Z",
  "status": "pending"
}
```

    Payment addresses are created a few seconds after the charge. Fetch the charge again to get them (next step).

    <Note>
      `amountNgn` is sent in **whole naira** (`"5000"` is ₦5,000) but returned in **kobo** (`"500000"`). `amount` is in the coin's smallest unit: USDC has 6 decimals, so `"3646209"` is 3.646209 USDC. `amount` already includes `feeAmount`, the LuminPay fee the customer pays on top.
    </Note>
  </Step>
  <Step title="Show the customer where to pay">
```bash
curl https://sandbox-api.luminpay.co/charges/6f1c2d3e-8a9b-4c5d-9e0f-1a2b3c4d5e6f \
  -H "Authorization: Bearer $LUMINPAY_TEST_KEY"
```

    `addresses` lists one address per network the customer can pay on, each with its own `amount` and `scale` (number of decimals). Show the address and amount for the network your customer picks, or send them to the hosted checkout page at `https://sandbox.luminpay.co/pay/{chargeId}`.
  </Step>
  <Step title="Pay with test coins">
    Send the exact amount from a testnet wallet. [Networks and test coins](/guides/networks) lists the faucets for each network.
  </Step>
  <Step title="Get told when it's paid">
    Add a webhook endpoint and LuminPay sends `charge.paid` when the payment confirms. See [Webhooks](/guides/webhooks). Until then you can poll `GET /charges/{id}`, which returns `status: "paid"` and the `txHash`.
  </Step>
  <Step title="Go live">
    When your integration works in Sandbox, follow [Going live](/environments#going-live). Your code stays the same; only the base URL and key change.
  </Step>
</Steps>
