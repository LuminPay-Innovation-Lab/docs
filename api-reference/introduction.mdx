Send `Authorization: Bearer <key>` on every request and `Content-Type: application/json` on requests with a body. See [Authentication](/authentication).

## Conventions

- **Money is sent as strings of digits**, never numbers, so nothing is lost to rounding. Naira amounts you send are whole naira (`"25000"`); naira amounts LuminPay returns are kobo (`"2500000"`). Coin amounts are in the coin's smallest unit; divide by 10 to the power of `scale`.
- **Ids are UUIDs.** A malformed id returns `400`.
- **Lists** return at most 100 items. Charges are paged with `cursor`.
- **Errors** follow one format. See [Errors](/guides/errors).
- **Rate limit:** 100 requests a minute per IP address.
