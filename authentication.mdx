---
title: "Authentication"
description: "Authenticate API requests with a secret key"
---

Send your API key as a Bearer token on every request:

```bash
curl https://sandbox-api.luminpay.co/charges \
  -H "Authorization: Bearer lmp_test_..."
```

| Key | Works with |
|---|---|
| `lmp_test_...` | `https://sandbox-api.luminpay.co` |
| `lmp_live_...` | `https://api.luminpay.co` |

## Managing keys

Create and revoke keys in your dashboard under **Developers → API keys**. For security, keys can't be created, listed or revoked with an API key; only a signed-in dashboard user can do it.

- The full key is shown once, when you create it. LuminPay stores only a hash.
- Revoked keys stop working immediately.
- To rotate a key, create the new one, deploy it, then revoke the old one.

<Warning>
  Your API key can create charges and read your payments. Keep it on your server. Never put it in a website, mobile app, or public repository. If a key leaks, revoke it straight away.
</Warning>

## Authentication errors

| Status | Message | What to do |
|---|---|---|
| `401` | `Missing or malformed Authorization header.` | Send `Authorization: Bearer <key>`. |
| `401` | `This is a Sandbox key (lmp_test_). Use it with https://sandbox-api.luminpay.co.` | Use the base URL that matches the key. |
| `401` | `This is a Live key (lmp_live_). Use it with https://api.luminpay.co.` | Use the base URL that matches the key. |
| `401` | `Invalid or revoked API key.` | Check the key was copied in full, or create a new one. |
